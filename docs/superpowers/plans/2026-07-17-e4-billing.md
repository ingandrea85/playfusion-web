# E4 Admin — billing / subscription (B) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a per-tenant subscription (plan/status/renewal) to the E4 Admin org detail — change plan and status, price derived from the plan.

**Architecture:** A `Subscription` entity (one per org) + a shared `PLANS` table (price derived, not stored) in the mock store, seeded per org. The org detail screen gains an "Abbonamento" card. No invoices (deferred). No framework.

**Tech Stack:** Vite MPA, vanilla TypeScript, Vitest + jsdom, plain HTML/CSS.

## Global Constraints

- **No framework**; vanilla TS/HTML/CSS; no backend/network; deterministic.
- **Price is derived from `PLANS`, never stored** on the subscription.
- **One subscription per org**; seeded for all 4.
- **Do not disturb E1/E3** (additive).
- **Reuse Matchday classes** (`.pf-badge`, `.pf-field`, `.pf-card`, `.pf-mono`, `.pf-row`); no hardcoded hex in screens.
- Plans: `FREE €0`, `PRO €19`, `BUSINESS €29` (monthly, illustrative). Statuses: `TRIAL`, `ACTIVE`, `PAST_DUE`.

export const PLANS: Array<{ key: PlanKey; label: string; priceMonthly: number }> = [

  { key: 'PRO', label: 'Pro', priceMonthly: 19 },

Add `Subscription`, `PlanKey`, `SubStatus` to the type import. Append the ops:

```ts
export function getSubscription(orgId: string): Subscription | undefined {
  return load().subscriptions.find(s => s.organizationId === orgId)
}
export function setSubscriptionPlan(orgId: string, plan: PlanKey): void {
  const state = load()
  const s = state.subscriptions.find(x => x.organizationId === orgId); if (s) s.plan = plan
  save(state)
}
export function setSubscriptionStatus(orgId: string, status: SubStatus): void {
  const state = load()
  const s = state.subscriptions.find(x => x.organizationId === orgId); if (s) s.status = status
  save(state)
}
```
